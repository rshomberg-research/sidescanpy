Theory
======

Why sidescan imagery looks the way it does, and what each processing
step undoes. Each page takes one idea, states the physics or the
reasoning first, then shows it on a real, openly licensed recording
with a measurement you can check.

The :doc:`/examples/index` show how to do a task with sidescanpy;
these pages explain why the steps are there. Each Theory page links to
the example that applies it, and each example back to its Theory page.

Like the examples, every page is a script in ``examples/theory/`` that
runs when this site is built, on recordings listed in
:doc:`/example_data`. Run one yourself with an output directory::

    python examples/theory/plot_four_published_chains.py out/

Some Theory pages compare sidescanpy with products other software
published from the same recordings, and download those products too:
they are larger than the example recordings (see each page).
